# Tech-currency review: ARCHITECTURE-SPINE.md (Unity 6000.6.7f1)

Verdict: Largely current and sound. No blocking errors. A few compile or setup traps and missing detail. Web search verified only the Input System version and the uGUI/TMP merge. The other items are from prior knowledge and should be confirmed in the 6000.6 docs at M3.

## Verified by search
- Input System 1.19.0 is the version listed for Unity 6.6 (6000.6) in the Unity manual. Note the manual page is still labelled "6.6 Alpha". OK, and the M3 pin is the right mitigation.
- uGUI 2.x (com.unity.ugui 2.0+) merged TextMeshPro; the standalone TMP package is deprecated. The Stack row is correct. TMP Essential Resources still have to be imported once into a new project.

## Findings
1. HIGH - Namespace `GMR.Debug` shadows `UnityEngine.Debug`. Inside any `namespace GMR.Runtime.*` or `GMR.Core.*`, a bare `Debug.Log` binds to the `GMR.Debug` namespace and fails with CS0234. The assembly exists and the namespace is declared by it. Fix: rename to `GMR.DevTools` (assembly `GMR.DevTools`), or ban bare `Debug` and require `UnityEngine.Debug`. The log prefix `[GMR/<Area>]` is unaffected.
2. MED - Same shadowing for `EncounterContext.Time` (the TimeScaleService field, vs `UnityEngine.Time`) and `GMR.Core.Input` (vs `UnityEngine.Input`). Fix: rename the field to `TimeScale` and the namespace area to `InputBuffering`.
3. MED - `InputTestFixture` (the PlayMode `SecondPlayerSmokeTest`) lives in the `Unity.InputSystem.TestFramework` assembly. The test asmdef must reference it. For tests of Core only, `noEngineReferences` is not possible, because Core uses Vector2 and ScriptableObject. Fix: state this explicitly in AD-1, and use `Physics2D.simulationMode`/`Physics2D.autoSyncTransforms` as needed in PlayMode tests.
4. MED - Domain reload off (AD-5): the static ban covers C# fields but not (a) ScriptableObject runtime mutation, which persists across Play sessions and can corrupt tuning assets, (b) `static event`s, and (c) InputSystem state (`InputSystem.onDeviceChange` subscriptions, `PlayerInput` leftovers). Fix: treat SOs as read-only at runtime (clone with `Instantiate` if mutated), ban `static event`, add `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` reset for any unavoidable static.
5. MED - `.gitattributes` with `merge=unityyamlmerge` does nothing unless each clone also sets `git config merge.unityyamlmerge.driver` (with the UnityYAMLMerge path). Add a one-time setup script to the M3 checklist alongside the LFS install. Also set `UnityEngine` Smart Merge not required if all scenes stay single-author.
6. LOW - Physics2D API: specify the `Physics2D.OverlapCircle/OverlapBox(pos, size, angle, ContactFilter2D, Collider2D[] results)` overloads. The `*NonAlloc` variants are obsolete in Unity 6. Use `Rigidbody2D.linearVelocity`, not `.velocity` (obsolete, now removed or erroring in later 6.x). Use `FindFirstObjectByType`, not `FindObjectOfType`. The Spine itself says "Nothing calls FindObjectOfType", which is fine but make the replacement explicit in BannedApiTests.
7. LOW - Pixel Perfect: the Stack row lists "2D Pixel Perfect" and "URP built-in PixelPerfectCamera" together. In URP 2D only the URP `UnityEngine.Rendering.Universal.PixelPerfectCamera` component applies. The legacy `com.unity.2d.pixel-perfect` package is built-in-RP only and conflicts if both are installed. Fix: do not install the package.
8. LOW - Batchmode CLI: give exact flags. `-batchmode -runTests -testPlatform EditMode|PlayMode -testResults <xml> -logFile -`, without `-quit` (the test runner exits itself), and without `-nographics` for PlayMode (URP/2D rendering). Do not run it while the Editor has the same project open.
9. INFO - Confirmed fine as written: `PlayerInputManager` with `JoinPlayersManually` and `JoinPlayer(index, splitScreenIndex, controlScheme, pairWithDevice)`; `SaveBindingOverridesAsJson`/`LoadBindingOverridesFromJson` (per-Player `PlayerInput.actions` is a clone); `InputSystemUIInputModule`; `AudioSource.PlayScheduled` with `AudioSettings.dspTime` (DSP time is unaffected by `Time.timeScale`, good for hitstop); `UnityEngine.Pool.ObjectPool<T>`; asmdef `defineConstraints` `UNITY_EDITOR || DEVELOPMENT_BUILD` (OR syntax supported); Enter Play Mode with domain reload off.
